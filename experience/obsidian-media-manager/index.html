      Obsidian Media Content Manager

      Relational Database System • Knowledge Management • Personal Media Library

      Project Overview

      Built a sophisticated media content management system using Obsidian, leveraging its powerful linking and database capabilities to create a comprehensive personal media library. The system tracks and organizes all forms of media consumption with an aesthetically beautiful yet highly functional interface.

      Supported Media Types
      📚 Books 🎬 Movies 🎌 Anime 📺 TV Series 📄 Academic Articles 💬 Tweets & Quotes
      Relational Database Architecture

      🔗 Cross-Media Linking

      Connect related content across formats—link a book to its movie adaptation, or an anime to its manga source material.

      👥 Characters & Staff

      Track characters across appearances and link to voice actors, authors, directors, and other staff members.

      🏷️ Smart Tagging

      Flexible taxonomy system for genres, themes, mood, and custom categories.

      📊 Status Tracking

      Monitor consumption progress with customizable status properties.

      Status Properties
      📖 Reading 👀 Watching ✅ Complete ⏸️ On Hold 🚫 Canceled 📋 Plan to Read 🎯 Plan to Watch ⭐ Favorites 🔄 Re-reading 🔁 Re-watching
      Design Philosophy

      Designed with a focus on both aesthetic beauty and functional efficiency. The system provides:

      • Visual Appeal — Clean layouts with cover images, color-coded categories, and intuitive navigation
      • Quick Access — Fast filtering and search across the entire library
      • Deep Connections — Discover relationships between content through bidirectional linking
      • Flexible Structure — Easily adapt to track any type of content from academic papers to social media posts
